# Стенд для сквозной проверки (e2e)

Презентон с включённым входом, но вместо платных сервисов — поддельные:
текстовая модель (OpenAI-совместимая), arckep для картинок и ЮKassa. Так
можно пройти весь путь (создание с фото → план → слайды → Студия →
раскадровка → пополнение баланса) и устроить сбои, ничего не тратя.
Стенд берёт `nginx.conf` из репозитория.

- Presenton: http://127.0.0.1:5057 (контейнер `presenton-e2e`)
- Поддельные сервисы: http://127.0.0.1:9056 (контейнер `presenton-e2e-fake`)

## Запуск

Нужны собранный фронтенд (`servers/nextjs/.next-build`) и образ
`ghcr.io/presenton/presenton:latest`. Первый старт скачивает модели поиска
(нужен интернет).

```bash
sh scripts/e2e-stand/run_stand.sh
sh scripts/e2e-stand/run_all.sh
```

`run_all.sh` создаёт пользователей (администратор, обычный с балансом 100 000 ₽
для атак на Студию и плательщик; пароли — в `accounts.json`, в git не попадает)
и запускает:

| Файл | Что проверяет |
|---|---|
| `attack_studio.py` | вход, чужие картинки, вредные ссылки и файлы, «бомбы», сбои arckep (500, 429, баланс, права ключа, недоступен), очередь задач arckep |
| `attack_photos.py` | фото в слайдах: чужие презентации и файлы, пути к системным файлам, подбор при сбое модели |
| `attack_roles.py` | права администратора, ошибки на русском и английском |
| `attack_billing.py` | оплата: цены, списание и возврат, гонки (10 запросов на 75 ₽), ранний отказ, пополнение через ЮKassa, подделанные и повторные уведомления, недоплата, отмена, сохранение карты, автопополнение раз в час, API-генерация |
| `ui_e2e.cjs` | интерфейс в браузере без окна: генерация → раскадровка (12 ракурсов, по 3 сразу, повтор одного), кисть |
| `billing_ui.cjs` | цена на кнопках, баланс в панелях, окно «Пополните баланс», оплата на странице ЮKassa и возврат, автопополнение, вкладка «Балансы», раздел «Оплата» |
| `mobile.cjs` | ширина телефона: нет горизонтальной прокрутки |
| `anon.cjs` | без входа — только форма входа |

`attack_studio.py --slow` дополнительно ждёт «зависший» arckep (около минуты).
`attack_studio.py` один раз останавливает поддельный сервис, чтобы проверить «arckep недоступен».

## Редеплой как на RelaxNet

```bash
python scripts/e2e-stand/relaxnet_redeploy.py
```

Отдельный контейнер `presenton-relax` (http://127.0.0.1:5058, порт 8080 внутри) с PostgreSQL
(`presenton-relax-pg`), без тома для `/app_data` и с копией файлов в поддельном Storage API.
Контейнер несколько раз удаляется и поднимается заново: пользователи, балансы, вход и файлы
должны сохраниться, в том числе при недоступном CDN и недоступном хранилище. Логи остановленных
контейнеров — в `.relax-logs/`. Подробнее — [`DEPLOY_RELAXNET.md`](../../DEPLOY_RELAXNET.md).

## Модели Студии

```bash
python scripts/e2e-stand/attack_models.py
docker cp scripts/e2e-stand/models_ui.cjs presenton-models:/tmp/e2e/ && docker exec -w /tmp/e2e -e NODE_PATH=/app/presentation-export/node_modules presenton-models node models_ui.cjs
```

Отдельный контейнер `presenton-models` (http://127.0.0.1:5059): каталог и цены поддельного arckep,
«Админка → Модели» (включение, названия, режимы, наценка, своя себестоимость, модель для слайдов),
цены и отказ без цены, картинки слайдов через выбранную модель. `models_ui.cjs` — то же в браузере.

## Сбои вручную

```bash
curl -X POST 127.0.0.1:9056/control -H 'Content-Type: application/json' -d '{"llm": "fail_next:2"}'
```

Модель: `ok`, `http500`, `fail_next:N` (N ответов 504), `empty`, `garbage`, `hang`;
задержка ответа — `llm_delay` (секунды).
arckep: `ok`, `create500`, `create429`, `balance`, `scope`, `job_failed`, `garbage`,
`bad_image`, `download404`, `upload500`, `hang_create`.
ЮKassa (`"yookassa"`): `ok`, `create500`, `saved_fail` (списания с сохранённой карты отклоняются).
Оценка цены arckep (`"estimate"`): `ok`, `fail`, `odd` (цена в другом поле). Storage API RelaxNet (`"storage"`): `ok`, `cdn_down` (CDN отвечает 503, работает запасная ссылка), `upload500`, `down`.
Страница оплаты — `http://presenton-e2e-fake:9000/yookassa/pay/<id>` (кнопки «Оплатить» / «Отменить»);
после оплаты поддельная ЮKassa шлёт уведомление с неверной суммой — Презентон обязан перепроверить платёж.
`GET /control` показывает журнал запросов (модели, промпты, число одновременных задач).

## Остановить

```bash
docker rm -f presenton-e2e presenton-e2e-fake presenton-relax presenton-relax-pg
```
