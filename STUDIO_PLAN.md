## 2. Что есть сейчас
- **Presenton.** Next.js 16 (фронт) + FastAPI (сервер, БД, вход, хранилище `app_data`). Картинки пользователя лежат в его папке `app_data/images/users/<id>`, у каждой — запись `ImageAsset`: владелец, путь, `extras` JSON.
- **AI Image Studio** (`D:\Image_service`). Next.js 14 + Prisma/PostgreSQL, вход по ссылке на почту, кредиты и оплата, провайдеры Jetstream и arckep.
  - Режимы:
    - генерация по описанию;
    - правка всего изображения;
    - «Волшебная кисть»: маска, после генерации результат склеивается с оригиналом строго по маске;
    - «Улучшить качество» и «Убрать фон» — специальные инструкции модели;
    - «Работа с референсом» — вставка объекта или логотипа;
    - Storyboard — несколько ракурсов одной сцены.
  - arckep работает асинхронно: `POST /uploads` для картинок, `POST /images/generations` создаёт задачу, затем опрос `GET /images/generations/{id}`. Лимит — 5 задач на ключ.
- ⚠️ **Прикреплённые фото сейчас НЕ попадают в слайды.** При создании презентации Presenton только распознаёт на них текст (OCR) как материал. Картинки слайдов генерируются или берутся из фотостоков. Для идеи «подправил фото → добавил в презентацию» нужна новая функция (шаг 3.3).

## 3. Как устроим
- **Один сервис.** Студия — модуль Presenton: один вход, один дизайн (шрифты Syne/Manrope, цвета Presenton), RU/EN.
- **Сервер (FastAPI):**
  - `api/v1/studio/*` + `services/studio/`: клиент arckep (загрузка, задача, опрос, скачивание), режимы Студии;
  - склейка по маске и масштабирование — Pillow;
  - ошибки через существующую локализацию (`http_error`).
- **Хранение без миграций.** Результат — файл в папке пользователя плюс `ImageAsset` с `extras = {source: "studio", mode, prompt, model, parent}`. История Студии — эти записи. Каждая картинка Студии сразу доступна в редакторе слайдов.
- **Настройки (только администратор).**
  - Адрес и ключ arckep для Студии. Пустой ключ — берётся ключ поиска, если поиск тоже идёт через arckep.
  - Модели: Nano Banana 2 (`gemini-3.1-flash-image`), Nano Banana Pro (`gemini-3-pro-image`), ChatGPT Images 2 (`gpt-image-2`).
- **Интерфейс:**
  - группа «Студия» в левой панели;
  - страницы `/studio` (генерация), `/studio/brush`, `/studio/reference`, `/studio/storyboard`;
  - верхняя панель Студии;
  - общий компонент **«Панель Студии»** (выезжает справа) — для страницы создания и для редактора.

## 6. Заметки по реализации
- «Работа с референсом» сделана иначе, чем в исходной Студии: там объект вырезался локально (rembg) и грубо вклеивался в прямоугольник, а модель «вписывала» его. Здесь модель получает фото, маску места и объект за один запрос, затем результат склеивается с оригиналом по маске. Отдельного «Убрать фон у объекта» нет. Если качество вставки окажется хуже — вернуть вариант с вклейкой.
- Склейка по маске подгоняет тон перерисованного кадра к оригиналу (модели слегка сдвигают цвет всего кадра → был ореол вокруг правки).
- Мобильной вёрстки нет у всего кабинета Presenton (левая панель 114 px); Студия ведёт себя так же, как главная.
