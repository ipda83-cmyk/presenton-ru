## 2. Что есть сейчас
- **Presenton.** Next.js 16 (фронт) + FastAPI (сервер, БД, вход, хранилище `app_data`). Картинки пользователя лежат в его папке `app_data/images/users/<id>`, у каждой — запись `ImageAsset`: владелец, путь, `extras` JSON.
- **AI Image Studio** (`D:\Image_service`). Next.js 14 + Prisma/PostgreSQL, вход по ссылке на почту, кредиты и оплата, провайдеры Jetstream и arckep.
  - Режимы:
    - генерация по описанию;
    - правка всего изображения;
    - «Волшебная кисть»: маска, после генерации результат склеивается с оригиналом строго по маске;
    - «Улучшить качество» и «Убрать фон» — специальные инструкции модели;
    - «Работа с референсом» — вставка объекта или логотипа;
    - Storyboard — несколько ракурсов одной сцены.
  - arckep работает асинхронно: `POST /uploads` для картинок, `POST /images/generations` создаёт задачу, затем опрос `GET /images/generations/{id}`. Лимит — 5 задач на ключ.
- ⚠️ **Прикреплённые фото сейчас НЕ попадают в слайды.** При создании презентации Presenton только распознаёт на них текст (OCR) как материал. Картинки слайдов генерируются или берутся из фотостоков. Для идеи «подправил фото → добавил в презентацию» нужна новая функция (шаг 3.3).

## 3. Как устроим
- **Один сервис.** Студия — модуль Presenton: один вход, один дизайн (шрифты Syne/Manrope, цвета Presenton), RU/EN.
- **Сервер (FastAPI):**
  - `api/v1/studio/*` + `services/studio/`: клиент arckep (загрузка, задача, опрос, скачивание), режимы Студии;
  - склейка по маске и масштабирование — Pillow;
  - ошибки через существующую локализацию (`http_error`).
- **Хранение без миграций.** Результат — файл в папке пользователя плюс `ImageAsset` с `extras = {source: "studio", mode, prompt, model, parent}`. История Студии — эти записи. Каждая картинка Студии сразу доступна в редакторе слайдов.
- **Настройки (только администратор).**
  - Адрес и ключ arckep для Студии. Пустой ключ — берётся ключ поиска, если поиск тоже идёт через arckep.
  - Модели: Nano Banana 2 (`gemini-3.1-flash-image`), Nano Banana Pro (`gemini-3-pro-image`), ChatGPT Images 2 (`gpt-image-2`).
- **Интерфейс:**
  - группа «Студия» в левой панели;
  - страницы `/studio` (генерация), `/studio/brush`, `/studio/reference`, `/studio/storyboard`;
  - верхняя панель Студии;
  - общий компонент **«Панель Студии»** (выезжает справа) — для страницы создания и для редактора.

## 6. Заметки по реализации
- «Работа с референсом» сделана иначе, чем в исходной Студии: там объект вырезался локально (rembg) и грубо вклеивался в прямоугольник, а модель «вписывала» его. Здесь модель получает фото, маску места и объект за один запрос, затем результат склеивается с оригиналом по маске. Отдельного «Убрать фон у объекта» нет. 11.10.2026 проверено вживую: качество зависит от модели, решили оставить как есть.
- Склейка по маске подгоняет тон перерисованного кадра к оригиналу (модели слегка сдвигают цвет всего кадра → был ореол вокруг правки).
- Телефон (< 768 px): левая панель кабинета сворачивается в верхнюю строку с кнопкой «Меню» (выезжающая панель с теми же разделами и Студией); шапки страниц переносятся, настройки идут списком над содержимым. На компьютере всё как раньше.
- Фото в слайдах (3.3): при создании прикреплённые PNG/JPG/WebP сохраняются в картинки пользователя и в запись `slide_photos:<id>` (ключ-значение, без миграций). Когда план готов, текстовая модель с поддержкой изображений одним запросом раскладывает фото по слайдам; если модель картинки не принимает — по порядку (пользователь видит, каким способом). На странице плана — блок «Ваши фото»: выбор слайда, перетаскивание на карточку, «Подобрать заново»; фото переезжают вместе со слайдом при перестановке и переносятся при «Пересоздать план». При подготовке слайдам с фото даётся макет с местом под картинку, фото учитывают сдвиг из-за оглавления; при генерации фото встают в первые места под картинки.
- В «умном» режиме (слайды сразу в HTML, без макетов) фото пока не вставляются — отдельная задача.
- Панель Студии (3.4) — общий компонент `components/studio/StudioPanel.tsx` (он же пойдёт в редактор, 3.5): лента фото, режимы «Описать изменение», «Кисть», «Улучшить», «Убрать фон», «До/После», правки цепочкой, «Добавить в презентацию». Режима «Работа с референсом» в панели нет — он остаётся в разделе Студии. Кнопка «Studio» у фото появляется, только когда Студия настроена; отредактированное фото заменяет вложение (файл `<имя>-studio.png`).
- Студия в редакторе (3.5): кнопка «Studio» в панели инструментов картинки (двойной щелчок по фото на слайде) — основной редактор шаблонов; «Применить к слайду» меняет картинку, отменяется обычным «Отменить». Панель помечена `data-inline-edit-ignore`, чтобы редактор не снимал выделение и не перехватывал клавиши. В «умном» режиме кнопка в старом редакторе картинок: панель Студии открывается вместо его выезжающего окна (проверено только сборкой — на стенде нет «умных» презентаций).
- Студия принимает только свои картинки (`/app_data/...`), стандартные (`/static/...`), data URL и публичные ссылки (скачиваются с проверкой адреса — без внутренних адресов). Произвольные пути на сервере не читаются; то же для фото слайдов.
- Storyboard (3.6): `/studio/storyboard`, вкладка «Storyboard» в верхней панели Студии. Референс (загрузка или история) + 12 ракурсов в трёх группах, уточнение, модель только Gemini, разрешение. Каждый ракурс — отдельный запрос `POST /api/v1/studio/storyboard` (по 3 одновременно), результаты появляются по мере готовности, неудачный можно повторить; загруженный референс сохраняется один раз. С результата генерации — кнопка «Раскадровка».
- Проверка (3.7): отдельный стенд `scripts/e2e-stand` — Presenton со входом и поддельными моделью и arckep (бесплатно, со сбоями по команде). Пройдено вживую: создание с 3 фото → правка фото в панели Студии → план → фото на слайдах → генерация при сбоях модели → «Studio» в редакторе → «Применить к слайду» → сохранение; раскадровка 12 ракурсов, кисть, телефон, права, RU/EN — 160 проверок. Найдено и исправлено: при недоступном arckep был 500 без объяснения (теперь «Сервис недоступен», 503); при нескольких пользователях сразу часть запросов падала с «слишком много запросов» (теперь общая очередь не больше 5 задач на ключ и повтор при «занято»).
- Оплата (3.8), решения 13.10.2026: платно — Студия и создание презентаций (картинки слайдов входят), 10 ₽ за слайд; картинки — как в исходной Студии (себестоимость arckep × 1,45: Nano Banana 2 — 12/18/27 ₽, Pro — 25/25/39 ₽, ChatGPT Images 2 — 2/11/38 ₽); новичкам 100 ₽; администраторы бесплатно; автопополнение с сохранённой картой.
  - Сервер: таблицы `billing_accounts`, `billing_entries`, `billing_payments` (+ миграция). Списание — один `UPDATE … WHERE balance >= цена`, возврат — ровно один раз. Студия платит после проверок и получает деньги назад при сбое arckep. Презентация: проверка баланса при создании, списание при подготовке слайдов; незавершённая генерация (ошибка, закрытая вкладка) повторяется бесплатно, после сохранения слайдов новая генерация снова платная; «умный» режим — при старте генерации; API — как только известно число слайдов, при ошибке возврат. Ответ 402 — «Недостаточно средств: нужно N ₽, на балансе M ₽.» (нехватка баланса arckep у сервиса — теперь 503).
  - ЮKassa: пополнение 100/500/1000/2000 ₽ с чеком 54-ФЗ (email обязателен — у аккаунтов Presenton только логин), зачисление только после проверки платежа в ЮKassa (уведомление или возврат пользователя на `/billing?payment=…`), проверка суммы и владельца; карта сохраняется по согласию; автопополнение — когда баланс ниже порога, не чаще раза в час, выключается после 3 неудач подряд.
  - Интерфейс: баланс и «Пополнить» в верхней панели Студии и в левой панели, страница «Баланс» (пополнение, автопополнение, цены, история), цены на кнопках («Сгенерировать · 12 ₽», «Продолжить · 50 ₽»), окно «Пополните баланс» на любом ответе 402 (ссылка открывает оплату в новой вкладке), вкладка «Балансы» в админке (начислить/списать с комментарием, история), раздел «Оплата» в настройках (вкл/выкл, цена слайда, бонус, shopId, секретный ключ, код НДС, оферта, адрес уведомлений).
  - Для запуска с настоящими деньгами: ключи магазина ЮKassa в «Настройки → Оплата»; в кабинете ЮKassa — HTTP-уведомления на `https://<сайт>/api/v1/billing/yookassa/webhook` (payment.succeeded, payment.canceled); ссылка на оферту, где описаны условия автопополнения; при docker-compose миграция применяется сама (`MIGRATE_DATABASE_ON_STARTUP=true`).
- nginx: обращения к серверам внутри контейнера — `127.0.0.1`, не `localhost` (он же ::1): после перезапуска первые одновременные запросы получали «502 no live upstreams» (найдено проверкой оплаты, воспроизведено 11–13 из 64, после исправления 0 из 192).
- Модели из каталога arckep (16.10.2026): список моделей больше не зашит в код. `services/studio/models.py` — реестр: каталог `GET {arckep}/models` (тип image, раз в сутки или кнопкой; без arckep — снимок `catalog_snapshot.json`, 37 моделей) плюс настройки администратора в «Админка → Модели»: какие модели видят пользователи, название, порядок, режимы (генерация / кисть и правка / референс / раскадровка — только те, что модель умеет по каталогу), модель по умолчанию, наценка (общая 1,45 и своя у модели), своя себестоимость по вариантам и модель для картинок слайдов (иначе — как в настройках провайдера картинок). Стартовый набор: Nano Banana 2.1 (`gemini-nano-banana-2.1`, вместо Nano Banana 2), Nano Banana Pro, ChatGPT Images 2.5 (`gpt-image-2.5-sunburst`), FLUX.2 Pro, Seedream 5.0 Pro, Recraft V4.1 Vector; остальные выключены. Старые ключи (`nano_banana_2` и т.п.) принимаются.
  - Цена картинки = себестоимость × наценка × количество, округление вверх один раз. Себестоимость: своя из админки → оценка arckep `POST /images/estimate` (кэш сутки, сырой ответ хранится в `studio:estimates`, разбор терпимый к форме ответа) → замеры первых моделей. Нет цены — платный пользователь получает отказ (503), а не бесплатную генерацию; администраторы генерируют без цены.
  - Запрос к arckep собирается по возможностям модели из каталога (пропорции, разрешение, качество, количество); у моделей gpt-image — фиксированный размер вместо пропорций.
  - Проверка: `scripts/e2e-stand/attack_models.py` (24 проверки на отдельном стенде с поддельным arckep) и `models_ui.cjs` (вкладка «Модели» и Студия в браузере).
